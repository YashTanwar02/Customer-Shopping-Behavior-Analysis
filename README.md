# 🛍️ Customer Shopping Behavior Analysis

An end-to-end **Data Analytics** project that analyzes customer shopping behavior using transactional data to uncover purchasing patterns, customer segments, product performance, and subscription trends.

The project combines **Python**, **PostgreSQL**, and **Power BI** to transform raw transactional data into actionable business insights and interactive dashboards.

---

## 📌 Project Overview

This project analyzes approximately **3,900 customer transactions** to answer key business questions related to customer behavior and purchasing trends.

The analysis focuses on:

- Customer demographics
- Shopping patterns
- Product performance
- Subscription behavior
- Revenue analysis
- Customer segmentation
- Business recommendations

## 📂 Dataset

The dataset contains **3,900 retail transactions** with customer demographics and purchase information.

### Key Features

- Customer Age
- Gender
- Location
- Subscription Status
- Product Category
- Item Purchased
- Purchase Amount
- Discount Applied
- Previous Purchases
- Purchase Frequency
- Shipping Type
- Review Rating
- Season

---

## 🛠 Data Preparation (Python)

The dataset was cleaned and prepared using Python.

### Data Cleaning

- Checked missing values
- Imputed missing review ratings using category-wise median
- Standardized column names
- Verified data consistency
- Removed redundant columns

### Feature Engineering

- Created customer age groups
- Generated purchase frequency features
- Prepared data for SQL analysis

### Database Integration

- Connected Python with PostgreSQL
- Loaded the cleaned dataset into the database for business analysis

## 🗄 SQL Business Analysis

Business questions answered using PostgreSQL include:

- Revenue by customer gender
- High-spending customers using discounts
- Top-rated products
- Shipping type comparison
- Subscriber vs Non-subscriber analysis
- Discount-dependent products
- Customer segmentation
- Top products by category
- Repeat buyers and subscription trends
- Revenue contribution by age group

## 💡 Key Business Insights

- Customer spending varies across demographics and purchasing behavior.
- Loyal customers contribute significantly to overall revenue.
- Subscription status influences purchasing patterns.
- Certain products rely heavily on discounts to drive sales.
- Shipping preferences impact average purchase value.
- High-rated products present strong cross-selling opportunities.

---

## ✅ Business Recommendations

- Increase subscriber retention through exclusive offers.
- Reward loyal customers with targeted loyalty programs.
- Optimize discount strategies to protect profit margins.
- Promote top-rated products through marketing campaigns.
- Target high-value customer segments with personalized promotions.
